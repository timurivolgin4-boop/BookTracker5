#Currency Converter 
Автор: Иволгин Тимур Владимирович

Описание
Это простое графическое приложение для конвертации валют. Оно позволяет выбрать исходную и целевую валюту, ввести сумму и получить результат по актуальному курсу с помощью внешнего API. Все операции сохраняются в историю, которую можно просмотреть прямо в приложении.

Технологии
Язык: Python 3.
GUI: Tkinter (стандартная библиотека).
API: exchangerate-api.com.
История: JSON-файл.
Требования
Python 3.7 или новее.
Библиотека requests (для работы с API).
Установка
Установите Python, если он ещё не установлен.
Установите зависимости:
bash
Копировать
pip install requests
Как получить API-ключ
Перейдите на сайт exchangerate-api.com.
Зарегистрируйтесь и получите бесплатный API-ключ.
Откройте файл main.py и замените строку:
python
Копировать
API_KEY = "ВАШ_API_КЛЮЧ"
на свой ключ.

Запуск приложения
Убедитесь, что все файлы проекта находятся в одной папке.
Запустите приложение:
bash
Копировать
python main.py
В появившемся окне:
выберите валюту «Из» и «В»;
введите сумму;
нажмите «Конвертировать».
Результат появится ниже, а операция будет добавлена в таблицу истории.
Структура файлов
Копировать
currency_converter/
│
├── main.py          # основной код приложения
├── history.json     # история операций (создаётся автоматически)
├── README.md        # этот файл
└── .gitignore       # файлы, которые не нужно добавлять в Git
Примеры использования
Конвертация 100 USD в EUR.
Просмотр истории всех операций.
Валидация ввода: только положительные числа.
